# CGPA Package Prediction

A Machine Learning web application that predicts an expected placement package based on a student's CGPA.

The project uses **Linear Regression** for prediction, **Flask** as the backend, and **HTML/CSS** for the user interface.

## 🚀 Features

* Predict expected package using CGPA
* Machine Learning model using Linear Regression
* Simple and user-friendly web interface
* Flask backend for connecting the ML model with the UI
* Real-time prediction through a web form

## 🛠️ Technologies Used

* Python
* NumPy
* Pandas
* Scikit-learn
* Flask
* HTML
* CSS
* Pickle

## ⚙️ How It Works

1. The placement dataset is used to train a Linear Regression model.
2. The trained model is saved as a `.pkl` file.
3. Flask loads the trained model.
4. The user enters their CGPA through the web interface.
5. Flask sends the CGPA to the trained model.
6. The model predicts the expected package.
7. The prediction is displayed on the webpage.

## 📌 Input

## 📤 Output

## 🧠 Machine Learning Model

The project uses **Linear Regression** to learn the relationship between CGPA and placement package.

The trained model is stored using Python's Pickle format and loaded by the Flask application during runtime.

## ⚠️ Disclaimer

The predicted package is an estimated value generated by the machine learning model. Actual placement packages can vary depending on skills, company, experience, interview performance, location, and other factors.
